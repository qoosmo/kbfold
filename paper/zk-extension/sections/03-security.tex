\section{Formal Security Model for Zero-Knowledge KBFold}\label{sec:security}
This chapter supplies the exact definitions and small proof obligations used to distinguish algebraic correctness, oracle proximity soundness, extraction, and zero knowledge. All the objects and probability spaces are finite. The notation for kernel encoding and folding is inherited from Chapters~1 and~2, while the adversarial verifier model is new and is stated independently of a particular implementation of a Merkle tree or a random oracle.
